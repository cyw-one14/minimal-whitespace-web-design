# 设计系统与品牌适配

适用于确定网站视觉、布局、排版和响应式。这里的数值是起始示例；已有品牌系统与当前任务优先。经验的适用边界见 [设计经验与适用边界](design-lessons.md)。

## 从内容选择表现方式

| 网站内容 | 可复用的设计方法 | 按新项目调整 |
| --- | --- | --- |
| 实物产品 | 大幅真实影像、无框产品展示、分组目录、统一详情 | 依产品数量、形态和决策所需参数安排密度 |
| 企业或专业服务 | 实景/工作过程建立信任，品牌叙事与负责人入口 | 证明材料可以是案例、过程或履历；不硬塞工厂与证书 |
| 个人作品 | 作品先行、主次不同的编排、简洁介绍与联系 | 按作品比例和阅读顺序构图，保留作者风格 |
| SaaS 营销页 | 真实界面说明用途，一段内容回答一个问题 | 不用装饰性图片替代功能证据；按实际产品提供试用入口 |
| 后台、工具、内容门户 | 统一基线、可靠状态、共享组件与内容源 | 优先效率、密度和阅读；大图与沉浸章节通常不适合主操作区 |

## 定一个简短的视觉方向

使用能落实到页面的描述，如“安静、可信、产品占主导；白色画布、深色正文、单一品牌强调色；大图和紧凑规格形成节奏”。随后明确色彩角色、字体角色、内容宽度和影像语言。

新品牌已有识别体系就继承。缺少体系且用户无偏好时，可用中性底色、清晰正文和一种强调色起稿。品牌主色可大胆使用，也可克制使用；判断它是否支撑内容与对比度，不要把某个案例的颜色或底色变成通用要求。

## 从参考提取设计依据

用户提供参考网站或截图时，先实际查看，再回答：主体与文字占多少空间；层级如何靠字号和留白成立；区块之间怎样改变节奏；交互为哪个任务服务。网址需要查看实际页面，截图只证明对应尺寸和状态，不能据此猜测全部交互。

选出适合当前内容的模式，说明适用理由，再替换成当前品牌的素材、信息与视觉参数。例如可借鉴“一幅主作品配两幅次作品”的主次关系，而不继承原网站的标志、文案、独特素材与固定比例。参考内容与目标用户任务冲突时，保留用户明确要求，再调整其余结构。

## 内容画布与统一边界

- 常规内容居中并封顶；页边距有上下限，避免超宽屏的 vw 内边距不断挤压正文。
- 首屏标题、后续区块标题、联系负责人等共享可识别的左基线。局部版式变化仍围绕这套基线组织。
- 图像区可以更宽，正文使用较窄的阅读宽度。不要为追求横向对齐让长段文字铺满大屏。
- 固定侧栏是明确占用的空间。用一个共享变量计算内容起点，移动任何章节时不能侵入侧栏；不要逐章靠负 margin 试位置。
- 窄屏解除桌面绝对定位和跨列对齐，让信息回到自然文档顺序。

下面只展示布局机制，可移植到项目现有 tokens。侧栏内容边界指最小内容起点；侧栏宽度包含实际导航文字，再预留 gap。

```css
:root {
  --content-max: 80rem;
  --page-gutter: clamp(1.25rem, 4vw, 4.5rem);
  --section-space: clamp(3.5rem, 7vw, 7rem);
  --nav-height: 4.75rem;
  --sidebar-width: 12rem;
  --sidebar-gap: 2rem;
}

.page-container {
  width: min(var(--content-max), calc(100% - 2 * var(--page-gutter)));
  margin-inline: auto;
}

.brand-stage {
  --content-boundary: calc(var(--page-gutter) + var(--sidebar-width) + var(--sidebar-gap));
  padding-inline-start: var(--content-boundary);
  padding-inline-end: var(--page-gutter);
}

.reading-column { max-inline-size: 68ch; }
.content-grid > * { min-inline-size: 0; }
[id] { scroll-margin-top: calc(var(--nav-height) + 1rem); }

/* 例示：实际切换点由内容是否挤压决定。 */
@media (max-width: 52rem) {
  .brand-stage { padding-inline: var(--page-gutter); }
}
```

画布宽度与断点是可调整参数。先用真实导航、最长标题和影像比例找出挤压位置，再决定内容宽度、断点与各设备的构图。

## 排版

- 字体承担不同职责：正文和操作文字清晰；展示标题可以有个性。不要为每个模块新增一种字体。
- 多语言选择覆盖目标字形的字体并保留回退；需要稳定加载时使用已有自托管方案。
- 正文、说明、标签形成清楚的层级；不能把所有文字降成灰色小字来制造“高级感”。
- 标题允许均衡换行。使用 min-width: 0、合理行长和 overflow-wrap；不通过全局 nowrap、缩小所有文字或强制裁切处理长语言。
- 明确的品牌文案可以保留用户确认的换行；其他语言自然排版，不照搬中文行数。
- 检查真实中文、日文、西里尔文字及带重音字符的显示，避免只有拉丁字体截图正确。

## 影像与容器

- 展示产品轮廓时优先透明图和 contain；叙事场景图按构图使用 cover，并逐断点检查主体是否被裁掉。
- 同组产品统一画布与视觉体量，在素材生成阶段归一化，不累积单型号 CSS 缩放补偿。横向组合产品可按实际视觉体量单独处理衍生图。
- 非对称布局靠主次与比例成立：一幅重点影像可以配两幅次级内容，但每项仍有足够空间。
- 背景、描边、阴影和圆角分别承担分区、边界、层级和触摸感，不默认全部叠加。
- 照片可以直接落在画布上；表单、工具和数据单元需要明确容器时就使用。无框不等于所有网站都不允许卡片。
- 品牌线条字等母题若适合新品牌，共享定位、透明度和裁切。装饰不传达必要信息、不遮住阅读和点击，也不强制每章出现。

## 响应式重构

宽屏检查内容封顶与文字行长；中屏检查导航、侧栏和双栏是否挤压；手机按信息顺序减少列数、解除桌面定位。不是只把整体缩小。

真实素材进入后再判断裁切与比例。允许手机使用独立构图，但保持主体与信息一致。长语言应参与结构判断：改变 gap、列宽、布局或断点，比不断缩字号更可靠。

验收覆盖宽屏、常用桌面、平板、窄手机，并查看关键断点前后。不得用 body 的 overflow-x: hidden 掩盖正文、按钮或菜单越界；装饰层需要裁切时只裁切装饰容器。

## 评估页面是否成立

先看主任务和主体是否清楚，再看区块间是否有节奏、内容是否共享边界、窄屏和长文本是否自然。最后看强调色、装饰和动效是否增加辨识与理解。若删掉装饰后页面层级失去结构，先修版式。
