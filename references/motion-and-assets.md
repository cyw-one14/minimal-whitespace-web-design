# 素材与动效

用于图片处理、轮播、入场、沉浸章节及对应故障。先完成无动画的可读布局，再添加有目的的增强。

## 素材流程

1. 搜索当前项目的品牌、产品、场景、作品和媒体库，了解实际文件尺寸、格式、透明边缘与使用权。
2. 保留原始资料；衍生图进入项目既有媒体目录。生产运行和验证所需资源不能只存在于 Git 忽略的个人素材目录。
3. 根据用途选格式和构图：透明产品可用 WebP，照片用适合当前管线的现代格式；标志、图标和二维码按清晰度与已有体系保留 SVG/PNG 等。
4. 为手机准备适当候选尺寸或独立构图。图片声明真实比例；使用框架图片能力或 srcset / sizes，避免手机默认取桌面大图。
5. 仅当前首屏主要图提高加载优先级；非首屏按需加载。多颜色产品不要先创建一组隐藏图片导致全部下载。
6. 在真实页面检查颜色、透明边缘、裁切、主体体量、二维码可读性与网络路径。

生成氛围图时保持真实产品设计，不添加暗示额外能力的接口、按钮或屏幕。不能生成证书、客户背书、真实工厂或联系人来替代事实。素材不齐时调整版式，或把影响交付的真实资料缺口交给用户确认。

## 动效用途与可见性

| 类型 | 合适用途 | 约束 |
| --- | --- | --- |
| 轻微淡入与上移 | 建立区块阅读顺序 | 位移克制；内容不会永远停在隐藏态 |
| 行内 stagger | 引导阅读同一组卡片 | 依实际布局行，组内有明确顺序 |
| 悬停上浮/缩放 | 提示可点击或突出产品轮廓 | 精细指针增强；不移动命中区域、不作为唯一提示 |
| 章节交叉淡入 | 连接明确的叙事主题 | 画面、目录、文档滚动保持一致 |
| 地图区域点亮 | 表达已确认的覆盖范围 | 底图独立可见；动画层失败不丢信息 |
| 自动轮播 | 展示多项同类内容 | 有手动控制与停止条件，阅读时间足够 |

微交互可以从 150–250ms、轻入场从 400–700ms、错开间隔从 60–100ms 起稿；这些是可调整的起始建议。时间与位移按阅读、响应速度和用户偏好调整。

基础 CSS 保持内容可见。只有能力已就绪且准备观察相应元素后，才局部进入等待动画的状态；已在视口内的内容及时显示。初始化错误、无 JS 或减少动态效果时直接恢复最终可读状态，不依赖动画完成回调才显示关键资料。

同一元素只有一个 transform / opacity 状态所有者。需要同时入场与悬停时分层包装，或合并在同一状态控制中；不能让两个库或两段脚本互相覆盖。

## 网格整行入场

关键经验：响应式网格行必须按实际布局测量，不能使用全局 index % 固定列数。

- 分别测量每个 Grid，按未受入场 transform 干扰的布局坐标分行；可用同一 offsetParent 下的 offsetTop，并容许像素舍入误差。
- 观察整行是否进入视口，触发后按真实视觉阅读方向错开。DOM 顺序与视觉顺序不一致时先处理语义；RTL 按语言阅读方向调整。
- 字体、图片和容器尺寸变化可能导致重排。重测未入场内容的行，保留已显示元素的标记，不再次隐藏。
- 记录读取阶段再统一写入状态，避免每个卡片读写交错造成频繁布局。
- 减少动态效果时无需观察或等待计时，直接显示。

相关验收包含 2/3/4 列、不满一行、多分组、断点切换、长标题和布局完成前后的变化。

## 自动播放与变体选择

一个明确的播放状态控制定时器。常见启动条件是：项目允许自动播放、存在多项、页面可见、组件在视口内、用户没有暂停，且未要求减少动态效果。组件卸载或状态变化时清理计时器，不叠加多个 interval。

新网站中，持续自动更新的内容提供可访问的暂停/停止或等效控制；指示器是按钮并说明目标。可聚焦内容进入焦点时避免自行切换。读屏与键盘应知道当前项。自动播放速度与操作方式服从阅读需求和无障碍要求。

颜色切换要原子更新当前图、候选尺寸、颜色名称、alt 和 aria-pressed。用户主动选定变体后，通常停止本次自动切换，保留他的选择；如果产品要求其他行为，遵循产品定义。单项不启动计时器。

需要慢网图像切换时，在候选就绪前保留已有可见内容。不要先清空现图造成闪白，也不要预下载全部大图。

## 原生文档滚动与沉浸章节

优先普通滚动和粘性目录。只有确实要求章节舞台时，才引入受控切换。

设计两种进入方式共用的状态：用户直接滚动/拖动原生滚动条，或点击目录/使用键盘。程序滚动期间标记来源，避免“滚动更新章节 → 章节更新再滚动”的反馈循环。

若拦截滚轮做章节跳转，阈值与锁定仅在舞台控制区域内生效；长内容到边界前仍允许阅读。惯性滚动不能连续跨多章；锁定结束后仍可继续使用。不要创建隐藏的内部滚动区或模拟轨道来替代浏览器文档。

键盘处理不能抢占输入框、编辑器或菜单的方向键。直接拖动原生滚动条时画面与目录同步。离开最后章节进入页脚后，停止章节强制归位。手机、缩放、较矮视口、长语言和减少动态效果必须能完整访问内容；复杂度不适合时改自然文档流。

## 分层地图与证书

灰色或中性底图默认完整可见。覆盖层可独立错开点亮，首次展示后保持最终状态；不依赖底图动画或解码才启动整章。未确认的国家、地区和数字不绘制成业务事实。

证书保持原比例、原色和清晰文本，不能用滤镜和颜色蒙层统一成品牌色。轮播和透视是展示方式，不能妨碍查看证据。移动端减小同时出现数量，不丢条目。需查看细节时提供适合的静态/放大路径。

## 定位动效问题

观察该元素进入视口前后的 opacity、transform、可见标记、计时器、Observer 目标、触发阈值和最终 DOM；再看实际网格行、重排与减少动态效果状态。

常见原因与处理：

- 一部分卡片提前显示：行计算或选择器分组错误，检查实际 Grid。
- 布局变单列：CMS 生成 DOM 失去分组，不能只提高 CSS 优先级。
- 章节或地图空白：必要内容被动画前置状态隐藏，拆开基础层和动画层。
- 动画后又跳回：多个状态所有者或滚动反馈循环，统一状态与触发来源。
- 刷新才正常：比较实际 HTML、资源版本与缓存响应；强刷成功不足以确定具体缓存层。

修复后验证最初失败条件及直接相关重排/状态，不通过增加随机延时掩盖原因。
