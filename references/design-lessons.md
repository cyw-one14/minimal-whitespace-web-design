# 设计经验与适用边界

这些方法来自实际网站迭代中的可复用经验。本公开版本将案例匿名化，仅保留通用方法，不依赖原项目的目录、资料或运行环境。

## 经验如何迁移

| 观察到的问题或取舍 | 可复用的方法 | 应用边界 |
| --- | --- | --- |
| 装饰压过真实产品或作品 | 让主体和可核实证据承担视觉表达 | 使用当前项目获准使用的素材 |
| 宽屏留白无限增大，正文反而挤压 | 居中封顶画布与有上下限的页边距 | 根据内容而非案例尺寸决定数值 |
| 内容移动进入固定导航区域 | 用共享变量表达侧栏占用边界 | 窄屏改自然布局，重新计算安全边距 |
| 每段使用相同卡片结构 | 用主次、比例与场景变化形成节奏 | 高密度工具界面优先操作效率 |
| 内容只有动画结束后才显示 | 基础信息默认可见，动画只做增强 | 无 JS、初始化失败与减少动态效果仍可访问 |
| 按固定列数推算导致网格漏动画 | 按实际布局逐 Grid 分行触发 | 重排保留已显示状态 |
| 内容编辑后双列变成单列 | DOM 分组是布局契约的一部分 | 先检查最终结构，再调整 CSS |
| 导航、搜索与详情的数据不同步 | 单一内容来源和共享模板 | 内容很少时不必引入数据库 |
| 新内容被旧浏览器翻译覆盖 | 每段业务文本保留有效内容所有者 | 迁移时撤掉被替代的覆盖逻辑 |
| 生产验证依赖开发者私人文件 | 必需内容和验证数据来自可部署来源 | 原始素材可继续只读保存 |
| 强刷正常被当作已定位缓存问题 | 检查实际 HTML、资源版本与缓存响应 | 刷新结果不能单独确定缓存层 |
| 历史实现与现行源码双写 | 明确唯一维护入口，历史基准只供对照 | 迁移应有真实维护收益 |
| 构建通过被当作网站已经上线 | 分别记录实现、检查、部署与线上证据 | 过去的检查不代表实时状态 |

## 按项目选择的参数

品牌、颜色、字体、内容宽度、断点、语言、页面数量、轮播速度、图像构图、表单、后台、CMS、部署平台和框架均按目标项目决定。

CSS 示例与动效时间范围是可调整的起点，不是统一规范。沉浸章节、证书画廊、市场地图和品牌线条字只在信息和使用场景适合时采用。
